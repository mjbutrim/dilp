# Package index

## Key functions

- [`dilp()`](https://mjbutrim.github.io/dilp/reference/dilp.md) :
  Generate DiLP results
- [`lma()`](https://mjbutrim.github.io/dilp/reference/lma.md) : Generate
  a suite of leaf mass per area results
- [`temp_slr()`](https://mjbutrim.github.io/dilp/reference/temp_slr.md)
  : Estimate temperature with simple linear regression
- [`precip_slr()`](https://mjbutrim.github.io/dilp/reference/precip_slr.md)
  : Estimate precipitation with simple linear regression

## Other functions

- [`dilp_cca()`](https://mjbutrim.github.io/dilp/reference/dilp_cca.md)
  : Test if site leaf physiognomy falls within the physiognomic space of
  the DiLP calibration dataset
- [`dilp_errors()`](https://mjbutrim.github.io/dilp/reference/dilp_errors.md)
  : Check for common errors in DiLP measurements
- [`dilp_outliers()`](https://mjbutrim.github.io/dilp/reference/dilp_outliers.md)
  : Identify outlier specimens
- [`dilp_processing()`](https://mjbutrim.github.io/dilp/reference/dilp_processing.md)
  : Process raw leaf physiognomic data
- [`calc_lma()`](https://mjbutrim.github.io/dilp/reference/calc_lma.md)
  : Generate leaf mass per area results
- [`view_regressions()`](https://mjbutrim.github.io/dilp/reference/view_regressions.md)
  : View preloaded regressions
