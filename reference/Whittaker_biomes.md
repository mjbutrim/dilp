# Whittaker Biome Data

Delineations of Whittaker biomes from
github.com/valentinitnelav/plotbiomes

## Usage

``` r
Whittaker_biomes
```

## Format

### `Whittaker_biomes`

A data frame with points mapping out Whittaker biome delineations.

github.com/valentinitnelav/plotbiomes
